# Tood Lsit 2: The Revenge

## Description:
- Application de liste de tâches avec gestion de catégories et priorités hardcodées
- Architecture MVP
- Permet de créer, éditer, effacer et visualiser des tâches
- Des filtres permettent d'afficher les taches en fonction de la catégorie, de la priorité et du statut de complétion
- Utilisation du swipe pour effacer les tâches
- Persistance des données via `SQLite`

## Prérequis
- `Android Studio Otter 3 Feature Drop (2025.2.3)` ou plus récent
- `SDK Android API 26+`
- `JDK 11`

## Installation
1. Cloner le dépôt en SSH ou HTTPS : `git clone <url>`
2. Ouvrir le projet dans Android Studio
3. Syncroniser Gradle

## Execution
- Soit sur émulateur ou sur un appareil physique dans Android Studio
